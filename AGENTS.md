# Instrucciones para Codex — Zyntra Cloud

Antes de diseñar o modificar la web:
1. Lee `docs/guia-de-identidad.md`.
2. Consulta `docs/manual-de-marca.pdf` cuando necesites verificar un detalle visual o normativo.
3. Usa `public/assets/logos/logo-original.svg` como archivo original del logotipo.
4. Respeta la paleta oficial: `#D2E4C4`, `#006992`, `#001D4A`, `#020300`.
5. No deformes, recolorees ni alteres el logotipo.
6. No inventes los nombres de las tipografías corporativas: el manual muestra muestras, pero no deja sus nombres claramente identificados en el texto disponible.
7. Mantén una estética tecnológica, precisa, sólida, modular y adaptable, dirigida a líderes de tecnología, operaciones y fundadores de empresas.
8. Antes de implementar una dirección visual importante, presenta una propuesta y solicita aprobación si el usuario no ha autorizado ya esa decisión.
9. No reemplaces los recursos originales ni elimines archivos del usuario sin permiso.

Al terminar cada tarea, indica qué archivos cambiaste y cómo ejecutar/probar el proyecto.
